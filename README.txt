ANEL DE MORFÁ - Fabric 1.21.1 (Java 21)

Compilar: instale Gradle (ou copie esta pasta 'src' para o template oficial do Fabric 1.21.1) e rode:
  gradle wrapper && ./gradlew build
O .jar sai em build/libs/. Precisa do Fabric API.

Como jogar:
- Ache o Anel de Morfá em baús de estruturas (25%). Botão direito = equipa para sempre.
- R = menu do anel | G = habilidade do mob.
- Mobs dropam Essência do mob (30%) e Essência de Morfá (20%, qualquer mob).
- Frasco de Morfá = garrafa de vidro + essência de Morfá (não é gasto ao criar mobs).
- Criar mob: Frasco + Essência de Morfá + Essência do mob + item do mob (ex.: carne podre = zumbi).
- Melhoria do Anel = diamante + pérola do fim + 4 essências de Morfá. Botão direito. Mais capacidade (nível máx. 5).

SEM PC (pelo celular): crie um repositório no GitHub, envie todos os arquivos desta pasta
(incluindo .github), abra a aba Actions, espere o 'build' ficar verde e baixe o artefato
'morfaring-jar'. Use o .jar que NÃO termina em -sources.
